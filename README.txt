КАК ПОЛУЧИТЬ APK (без Android Studio)

1. Зайдите на github.com и создайте бесплатный аккаунт (если нет).
2. Нажмите + -> New repository. Назовите, например, rotations. Нажмите Create repository.
3. В новом репозитории: Add file -> Upload files. Перетащите ВСЕ файлы и папки из этого архива
   (www, .github, package.json, capacitor.config.json). Нажмите Commit changes.
   Если папка .github не загрузилась (скрытая): Add file -> Create new file, в имени введите
   .github/workflows/android.yml и вставьте туда содержимое файла android.yml из архива.
4. Откройте вкладку Actions -> Build APK -> Run workflow. Подождите 5-10 минут, пока значок станет зелёным.
5. Откройте завершённый запуск, внизу в разделе Artifacts скачайте rotations-apk (zip), внутри будет app-debug.apk.
6. Перенесите APK на телефон (мессенджер, почта, кабель). Откройте файл и разрешите установку из этого источника.

ВАЖНО
- Данные хранятся на каждом телефоне отдельно. Общего расписания между телефонами пока нет.
- Если установите новую версию APK, сначала удалите старую (подпись меняется), иначе установка может не пройти.
  При удалении данные на этом телефоне пропадут.
- Чтобы обновить приложение, замените файл www/index.html в репозитории и снова запустите Build APK.
